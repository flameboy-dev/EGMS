# 🏫 Ever Green Model School (E.G.M.S) - Web Platform

Official repository for **Ever Green Model School (E.G.M.S)** website and web application platform.

> **"Where Little Minds Grow Into Bright Futures"**

---

## 📂 Repository Structure

- `frontend/` - React + Vite + Tailwind CSS v4 frontend web application.
- `backend/` - Backend API services and server configuration.

---

## ⚡ Quick Start (Frontend)

```bash
cd frontend
bun install
bun dev
```

For more details on the frontend setup, refer to the [frontend/README.md](./frontend/README.md).
